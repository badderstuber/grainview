Controls

  • VIEW / V — cycle WAVE→PARM→MOD→SET
  • Encoder turn ⟲⟳ / ↑↓ / scroll — page views; navigate in a screen
  • Push / Enter — dive in / confirm
  • BACK / Esc — up a level
  • SOUND‹ › / ,. — change sound (1–8)
  • SCENE / B — A / B
  • FILE / F — load / save

Model

  • VIEW button and encoder both switch the 4 views (tab strip up top).
  • PARM / MOD are view-only — turn the module's knobs, watch here.
  • In SET, push to dive in, turn to move, BACK to exit.
  • SOUND / SCENE apply across every view. FILE opens its own screen.
