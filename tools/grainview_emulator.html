Controls

  • VIEW / V — cycle WAVE→PARAM→MOD→SETTINGS
  • Encoder turn ⟲⟳ / ↑↓ / scroll — page views; navigate in a screen
  • Push / Enter — dive in / confirm
  • BACK / Esc — up a level
  • SOUND‹ › / ,. — change sound (1–8)
  • A/B / B — edited scene A / B
  • FILE / F — the card, opens on the sound's folder. .. or BACK = up to the root (PROJECT / WAVS / RECS / PRESETS / PROJECTS). FILE again = quick jump to the next folder

Model

  • VIEW button and encoder both switch the 4 views (page dots in the status line).
  • PARAM / MOD are view-only — turn the module's knobs, watch here.
  • SETTINGS = the focused sound's settings (SOUND‹› flips sounds). Push to dive in, push a row to edit (value inverts), turn to change, push = keep, BACK = cancel.
  • SETUP / S — everything else: MODULE / PRESET / SAMPLE (soon) / GRAINVIEW. SETUP again or BACK = close.
  • SOUND / SCENE apply across every view. FILE opens its own screen.
  • PRESETS / PROJECTS: push a slot for LOAD / SAVE / LOCK (or OPEN / SAVE NOW). Overwriting a preset needs a 2nd push; locked ones can't be saved over.
  • Turn a knob on the Multigrain → its value shows big for 1.5 s (SETUP › GRAINVIEW › Knob view).
