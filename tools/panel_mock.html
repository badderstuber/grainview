"GRAINVIEW" — companion screen module (8 HP · 3U), to scale

128×128 greyscale OLED · push-encoder · 7 buttons. 4-wire SWD ribbon to the Multigrain JTRACE on the back. Working title.

Layout

  • OLED 128×128 — top, 2.67 cm square.
  • Encoder (push) — page views; navigate; push to select.
  • BACK — up a level.
  • VIEW — cycle WAVE·PARAM·MOD·SETTINGS (all per sound).
  • FILE — SD load / save.
  • SOUND ‹ › — change sound 1–8.
  • A/B — toggle scene (the screen header shows it).
  • SETUP — module / preset / sample / GRAINVIEW settings.
  • A/B scene LEDs dropped 2026-10-13 — maybe tiny LEDs in the A/B legend when the panel is finalised.

Physical

  • Width: 8 HP = 4.03 cm
  • Height: 3U = 12.85 cm
  • Power: rack bus (+12 V → 3.3 V); VTREF sensed.
  • No front jacks — ribbon + power on the back.
