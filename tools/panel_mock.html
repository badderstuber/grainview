"GRAINVIEW" — companion screen module (8 HP · 3U), to scale

128×128 greyscale OLED + push-encoder + 4 buttons. Connects to the Multigrain's JTRACE via a 4-wire ribbon (on the back). Working title — rename freely.

Layout

  • OLED 128×128 — 2.67 cm square, top third. Waveform + params + browser.
  • Encoder (push) — scroll lists / change value; push = select.
  • BACK — up a level / exit.
  • LOAD — load selected WAV into the current slot.
  • A / B — toggle Scene A / B view.
  • FUNC — shift for secondary actions.
  • LED — link/activity (green = mirroring).

Physical

  • Width: 8 HP = 4.03 cm
  • Height: 3U = 12.85 cm
  • Power: rack bus (+12 V → 3.3 V); VTREF sensed from Multigrain.
  • No front jacks — link ribbon + power on the back.
